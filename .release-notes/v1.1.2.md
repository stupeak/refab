# Refab v1.1.2

Refab v1.1.2 fixes a false changed state in the `To Roblox` workflow.

## Fixes

- Already-applied local assets should no longer keep showing as changed after
  clicking `Apply`.
- Refab now tracks the local file hash that was applied to each target Instance,
  avoiding false diffs caused by plugin metadata.

## Upgrade

```powershell
rokit install
refab install-plugin
```

Restart Roblox Studio after updating the plugin.
