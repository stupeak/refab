# Refab v1.1.0

Refab v1.1.0 improves the asset sync workflow between Roblox Studio and local
project files.

## Highlights

- Cleaner `To Roblox` and `To Local` views with tree-based asset selection.
- New and changed assets are easier to scan before applying.
- Folder selection now updates child assets together.
- The CLI now has clearer `run`, `stop`, `status`, `scan`, and version commands.
- Connection messages explain what to check when Refab cannot connect.
- Asset scope now covers more Roblox content roots, including `ServerStorage`,
  `StarterPack`, `StarterPlayer`, `Lighting`, `SoundService`, and
  `MaterialService`.

## Install

- Download `Refab.rbxm` for the Studio plugin.
- Download the matching Refab CLI archive for your platform, or install through
  Rokit with `refab = "stupeak/refab@1.1.0"`.
