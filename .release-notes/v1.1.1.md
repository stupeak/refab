# Refab v1.1.1

Refab v1.1.1 makes local plugin installation easier for Rokit users.

## Highlights

- Added `refab install-plugin`.
- The command downloads the matching `Refab.rbxm` release asset and installs it
  into the local Roblox Studio Plugins folder.
- Existing local plugin files are overwritten, so updating is one command.
- Installation docs now focus on the Rokit-first workflow.

## Usage

```powershell
rokit install
refab install-plugin
refab run
```
